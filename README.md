## 👨‍💻 About Me

I'm an IT student and **Hybrid Developer** passionate about building digital solutions across software development, networking, infrastructure, and Internet of Things.

I enjoy working across different technology layers — from writing application code and designing databases to configuring Linux servers, managing deployments, and developing connected IoT systems.

### What I Do

- 💻 **Web Development** — Building modern frontend and backend applications.
- 🌐 **Networking** — Exploring computer networks, network infrastructure, and connectivity.
- ⚙️ **DevOps & Infrastructure** — Managing Linux servers, VPS, Nginx, and application deployment.
- 🔌 **IoT Development** — Building smart systems using microcontrollers, RFID, and real-time communication.
- 🗄️ **Database Management** — Working with relational databases and application data architecture.
